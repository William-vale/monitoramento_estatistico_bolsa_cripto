# 🎨 Frontend - Monitoramento Estatístico da Bolsa & Cripto

Este é o diretório da interface gráfica do projeto. Aqui você irá:

- Visualizar os dados coletados pelo backend
- Criar gráficos e análises
- Monitorar ativos em tempo real
- Filtrar e buscar ativos

```
frontend/

```

---

## 🚀 Próximos Passos

1. **Backend primeiro**: Certifique-se de que o backend está funcionando
   ```bash
   python backend/orquestrador.py teste
   ```

2. **Dados disponíveis**: Depois de executar o backend, você terá:
   - `backend/TRADE_B3/ativos_b3.json` - Ativos da B3
   - `backend/TRADE_CRIPTO/bybit_spot.json` - Cripto SPOT
   - `backend/TRADE_CRIPTO/bybit_futuros.json` - Cripto FUTUROS

3. **Frontend**: Aqui você pode criar:
   - Página HTML com tabelas de ativos
   - Gráficos com a distribuição de ativos
   - Sistema de filtros
   - Dashboard com informações em tempo real
